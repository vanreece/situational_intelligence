# Situational Intelligence Substrate

Exploratory work toward a system that surfaces *situational intelligence* — the right context, in the right form, to the right human, at the moment they need to make a decision — for senior operators running complex multi-vendor programs.

## Status

Early exploration. Not a product. Possibly a product someday.

## What's here

- `CLAUDE.md` — Orientation for working in this repo with Claude Code.
- `docs/architecture.md` — The architectural thesis: composed single-thesis LLM passes, binary-per-category classification, cost-tier hierarchy, calibration as compounding asset.
- `docs/goals.md` — The unknowns this project is trying to reduce.
- `docs/antigoals.md` — What this project is *not*. Read this when scope creep tempts.
- `docs/datasets.md` — Public datasets we're using and why.
- `docs/detector-catalog.md` — Running list of detector ideas with status.
- `docs/experiment-log.md` — What was tried, what was learned.

## How to read this repo

Start with `CLAUDE.md`. It links to everything else in the right order.
