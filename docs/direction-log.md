# Direction Log

The user's voice. Strategic decisions, redirections, opinions, gut reactions, and high-level guidance over time. Distinct from Claude's analysis so the user's perspective stays legible across sessions, and so the canonical docs (`goals.md`, `antigoals.md`, `architecture.md`) get refined deliberately rather than overwritten on each session.

## Conventions

- **Append-only.** Newest entries at the top. Old entries are not edited or deleted, even when superseded — the record of *what we believed when* is part of the value.
- **The user writes here.** Claude reads this file for context but does not edit, summarize, condense, or move content unless explicitly asked. When Claude has something to surface, that goes in conversation or in `experiment-log.md` — not here.
- **No template.** A journal, not a form. Entries can be a one-liner, a paragraph, or a long musing. Strategic intent lives here in raw form before it gets refined into the canonical docs.
- **Date-stamped.** Each entry starts with `## YYYY-MM-DD:` and a short title.
